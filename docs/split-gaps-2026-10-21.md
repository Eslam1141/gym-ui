## How to read this

- Library: 122 plan entries tagged, 107 distinct ids, 61 distinct moves (the same id is reused across plans, and one move can carry several ids). Every entry now has a `tools` tag: what the move requires.
- Moves per tool: none 20, dumbbell 18, bench 9, machine 7, cable 6, barbell 4, band 3, pullup_bar 1, table 1.
- A **part** is a piece of a muscle (for example "Upper chest" or "Hamstrings: hip hinge"). The 26 parts map onto the app's 20 muscle tags; traps sit under the "Lower back / traps" tag, so they are checked on their own.
- **Gap**: no library move whose main job is that part fits the toolset. Nothing can be scheduled for it, whatever the split, so the builder would have to borrow from a neighbouring part. The move named under "Fill with" is the cheapest missing move that closes it.
- **Thin**: the part has a move but fewer different moves than the split wants (a 5 or 6 day week should not repeat one move every session; women's plans want more glute and leg variety). Not a blocker.
- Gaps do not depend on sex or on the number of days, only on the toolset. Variety depends on all three.
- Kits: bodyweight is only `none`. Dumbbell, band and dumbbell + band + bench add to `none`. All home tools is dumbbell, band, bench, table, pullup_bar, kettlebell, jump_rope. Gym is every tool, including barbell, cable and machine.
- Barbell, cable and machine moves never appear in a home kit; the Playwright test `tests/split-tools.spec.js` enforces that.

### Tagging calls worth a second look

- **Lat Pulldown / Pull-up** is tagged `cable`: the library clip is the pulldown. A pull-up bar is an alternative the clip does not show, so Pull-ups is listed below as a missing move.
- **Goblet Squat** is tagged `dumbbell`; a kettlebell does the same job (the "Kettlebell Goblet Squat" row below is optional if the owner is happy for the existing clip to serve both).
- **Standing Calf Raise** is tagged `none`: it is already used bodyweight in the calisthenics plans (25-30 reps); a loaded version is not required.
- **Bulgarian Split Squat** is tagged `dumbbell + bench`; unloaded on a chair it works, but the clip shows the loaded move.
- **Pallof Press** is tagged `cable`; a band works too (listed as Band Pallof Press).
- **Chest-Supported Row** and **T-Bar Row** are tagged `machine` (gym plate-loaded / supported row). The dumbbell version is a separate move (Chest-Supported Dumbbell Row, `dumbbell + bench`).
- **Hanging Leg Raise** is tagged `pullup_bar`.
- The inverted row is `table`; Decline Push-ups, Hands-Elevated Push-ups and the Doorway Towel Row below assume household furniture and are tagged `none`.
